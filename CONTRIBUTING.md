# CONTRIBUIÇÃO

Obrigado por considerar contribuir para este projeto! Para manter a organização, siga as instruções abaixo. Este projeto busca construir um ecossistema de inteligência artificial multiagente open-source, e sua contribuição é essencial para evoluí-lo.

## Antes de começar

- Leia o README para entender a proposta do projeto
- Verifique se já existe uma issue relacionada ao que você quer fazer
- Caso não exista, crie uma nova issue descrevendo sua ideia

## Estrutura do projeto

/front-end → Interface do usuário (Next.js)
/back-end → Lógica da IA e agentes (Python)

## Visão do projeto

Lucy IA busca se tornar um sistema de IA multiagente modular, inteligente e open-source, permitindo colaboração global na construção de agentes especializados.
